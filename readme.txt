== Description ==

Picot Subscription Membership provides Stripe Checkout, Customer Portal support, paid member-only content, and one-time article purchases.

== Installation ==

1. Activate the plugin.
2. Configure Stripe test keys and webhooks in the Membership settings screen.
3. Create the membership pages, verify the checkout flow, and then configure live keys.
